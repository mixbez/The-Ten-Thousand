# Bot Commands for BotFather

Paste the following into BotFather via `/setcommands`:

---

```
start - Начать работу с ботом и создать профиль
timezone - Установить ваш часовой пояс
personality - Пройти анкету стиля коучинга заново
monthly - Ежемесячный аудит здоровья (доступен раз в 21 день)
stop - Приостановить все напоминания и уведомления
```

---

## Command Descriptions

| Command | Russian Description |
|---|---|
| `/start` | Начать работу с ботом и создать профиль |
| `/timezone` | Установить ваш часовой пояс |
| `/personality` | Пройти анкету стиля коучинга заново |
| `/monthly` | Ежемесячный аудит здоровья (доступен раз в 21 день) |
| `/stop` | Приостановить все напоминания и уведомления |

## How to Apply in BotFather

1. Open [@BotFather](https://t.me/BotFather) on Telegram
2. Send `/setcommands`
3. Select your bot
4. Paste the block above (without the triple backticks)
